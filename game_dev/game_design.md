# Game Design

- definição das regras do mundo do jogo e condições de vitória e derrota  
- definição da jogabilidade  
- definição do controle do jogador  
- definição da interface do usuário  
- definição da camera do jogador  
- definição dos níveis do jogo  
- definição do estilo artístico  
- modos de jogos (singleplayer, multiplayers, etc)  

Elementos de game design:

Motivação do jogador:
- desafios sempre servem como experiência de aprendizado e geram emoções ao serem superados  
- socialização - jogos podem provocar experiência social  
- Competitividade  
- Experiência emocional  
- Escapismo  


# Regras de um bom game design

- Conteúdo é tudo  
- Jogabilidade é mais importante que gráficos  
- Conhecer o perfil do jogador é muito importante  
- O jogo deve ser consistente e divertido em primeiro lugar  
- Teste ideias e obtenha feedback de outras pessoas  
- Comece pequeno - como planejar algo que nunca fez?  
- Pense nos jogadores que irão jogar o seu jogo! Encante-as! Só não tente agradar a todos  
- Busque inspirações em sua experiência de vida, coisas que você mais gosta, etc  
- Guarde boas ideias para sequências e expansões  
- Arquitete o jogo pensando em inclusão de DLC, expansões  
- Não deixe o jogador sem objetivos, mostre sempre que o jogador está progredindo  
- Dê recompensa aos jogadores sempre que o jogador cumprir algum objetivo  
- Crie algo que você possa amar  
- mundo consistente - o jogador precisa entender os resultados de suas ações  
- entender os limites do mundo - não inserir mecanismos que quebrem as regras do mundo do jogo  
- Mostre a direção: não deixe o jogador perdido ou "preso" em algum cenário  
- Progressão: mostre que o jogador está sempre progredindo para o desafio final  
- Imersão  
- Difucldades e falhas: faça o jogador fracassar algumas vezes.  
- Não ofereça desafios repetitivos  
- Deixe sempre o jogador no controle (permita o jogador pular cutscenes)  
- Utilize puzzles  


# Game Design Document

Game Design Document (GDD) é um documento que descreve todas as características do jogo.

Permite ter uma visão precisa de como será a versão final do jogo.  
Permite a comunicação entre os colaboradores para que todos entendam como deve ser a versão final do jogo.  
Muito útil para validar conceitos, repensar decisões, etc.  

Este documento é muitas vezes requerido pels publicadores de jogos para analisar um jogo demonstrativo. 

O que deve ter no gdd:

- conceito do jogo: nome do jogo, apresentação resumida do jogo, etc  
- público alvo  
- especificações técnicas  
- especificações do jogo  
- descrição da interface do jogador  
- sonorização
