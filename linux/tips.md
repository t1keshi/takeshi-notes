# Useful Annotation

##### Check versions

```
    $ lsb_release -a // versão do linux
    $ uname -m // arquitetura do processador
```

##### Adicionando usuário na lista de sudoers

```
    user@Debian:~$ su -
```

Digite a senha do root.

```
    $root@debian:~# usermod -aG sudo takeshi
```
