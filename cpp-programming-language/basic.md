# Basic Facilities

- notions of type; types and declarations; fundamental types; naming; scopes; initialization; simple type deduction; object lifetimes, type aliases  
- pointers; arrays and references  
- structures, unions and enumerations  
- statements: declarations as statements, selection statements, iteration statements, goto, comments  
- expressions: operators; constant expressions; implicit type conversion  
- select operations; logical operators; the conditional expression; increment and decrement; free store (new and delete); {}-lists; lambda expressions; explicit type conversions (static_cast and const_cast)  
- functions; function declarations and definitions; inline functions; constexpr functions; argument passing; overloaded functions; pre-and postconditions; pointers to functions; macros  
- exception handling: styles of error handling; exception guarantees; resource management; enforcing invariants; throw and catch; vector implementation  
- namespace; modularization and interface; composition using namespace  
- source files and programs; separate compilation; linkage; using header files; program start and termination
