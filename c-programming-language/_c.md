# C Programming Language  

**C** é uma linguagem de programação de propósito geral multiplataforma criada por **Dennis Ritchie** e teve a sua origem na programação do sistema operacional **UNIX** para as máquinas **DEC PDP-11**. O sistema operacional **UNIX**, compiladores C e, essencialmente, todos os programas UNIX foram escritos em C.  

# Especificação Padrão

- C89 (1989) - conhecido como C ANSI   
- C90 (1990)  
- C94 (1990)
- C95 (1995)
- C99 (1999)
- C11 (2011)
- C17 (2018)
- C20 (2024)
